# alt-scroll-to-zoom.user.js

Userscript that zooms and pans the whole page like a map, which is handy when your PC has no touchpad or touchscreen. Inspired by Google Maps.

| Action                    | Effect               |
| ------------------------- | -------------------- |
| `Alt` + mouse wheel       | Zoom the page in/out |
| `Alt` + left-drag         | Pan the zoomed page  |
| `Alt` + left double-click | Reset the zoom       |

Works on all `http://` and `https://` pages.

## Install

1. Install a userscript manager such as [Violentmonkey](https://violentmonkey.github.io/) or [Tampermonkey](https://www.tampermonkey.net/).
2. Open [alt-scroll-to-zoom.user.js (raw)](https://raw.githubusercontent.com/snomiao/alt-scroll-to-zoom.user.js/main/alt-scroll-to-zoom.user.js) and confirm the install.
